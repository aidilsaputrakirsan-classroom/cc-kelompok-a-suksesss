# Reflection Paper – Siti Nur Azizah Putri Awni

## Pendahuluan

Pada proyek SafeSpace yang dikembangkan dalam mata kuliah Komputasi Awan, saya berperan sebagai Lead QA & Documentation. Tanggung jawab utama saya adalah memastikan kualitas aplikasi melalui proses pengujian serta menyusun dokumentasi proyek yang dibutuhkan selama proses pengembangan. Melalui peran ini, saya terlibat dalam berbagai aktivitas seperti pengujian fungsional aplikasi, validasi endpoint API, penyusunan laporan pengujian, hingga penyusunan dokumentasi teknis yang mendukung pengembangan dan deployment aplikasi.

SafeSpace merupakan aplikasi berbasis web yang dirancang untuk membantu proses konsultasi antara siswa dan Guru Bimbingan Konseling (BK). Aplikasi ini dikembangkan menggunakan pendekatan cloud-native dan microservices sehingga memberikan pengalaman baru bagi saya dalam memahami implementasi konsep komputasi awan secara langsung dalam sebuah proyek nyata.

## Kontribusi dalam Proyek

Sebagai Lead QA & Documentation, saya memiliki tanggung jawab untuk memastikan bahwa fitur-fitur yang dikembangkan oleh tim dapat berjalan sesuai dengan kebutuhan sistem. Salah satu kontribusi utama yang saya lakukan adalah melakukan pengujian aplikasi menggunakan metode blackbox testing. Pengujian ini dilakukan dengan memvalidasi berbagai fitur dari sudut pandang pengguna tanpa melihat implementasi kode secara langsung.

Selain itu, saya juga melakukan pengujian API menggunakan Swagger UI untuk memastikan endpoint yang disediakan backend dapat menerima request dan menghasilkan response yang sesuai. Pengujian ini mencakup proses autentikasi menggunakan JWT, pengujian endpoint konsultasi, endpoint dashboard, hingga endpoint monitoring aplikasi.

Di bidang dokumentasi, saya berkontribusi dalam menyusun berbagai dokumen proyek seperti README, API Contract, Database Schema, Docker Architecture, Deployment Guide, Release Notes, serta dokumentasi hasil pengujian. Dokumentasi tersebut disusun untuk membantu proses pengembangan, deployment, dan pemeliharaan aplikasi sehingga seluruh anggota tim memiliki referensi yang jelas mengenai sistem yang dikembangkan.

Selain tugas utama tersebut, saya juga terlibat dalam proses diskusi dan evaluasi proyek bersama anggota tim lainnya untuk memastikan bahwa setiap bagian aplikasi dapat terintegrasi dengan baik.

## Tantangan yang Dihadapi

Selama proses pengembangan proyek, saya menghadapi beberapa tantangan yang cukup signifikan. Salah satu tantangan terbesar adalah koordinasi dan komunikasi antar anggota tim. Dalam proyek ini setiap anggota memiliki peran yang berbeda, seperti frontend, backend, DevOps, dan QA & Documentation. Karena pekerjaan yang dilakukan saling berkaitan, progres satu anggota sering kali menjadi dependensi bagi anggota lainnya.

Pada beberapa kesempatan, terdapat kondisi di mana komunikasi tidak berjalan secepat yang diharapkan. Respons yang terlambat terhadap diskusi atau pembaruan progres pekerjaan menyebabkan beberapa aktivitas harus menunggu terlebih dahulu sebelum dapat dilanjutkan. Situasi tersebut memberikan pelajaran bahwa komunikasi merupakan salah satu faktor penting dalam keberhasilan sebuah proyek perangkat lunak, terutama ketika pengembangan dilakukan secara kolaboratif.

Tantangan lainnya berasal dari peran saya sebagai Lead QA & Documentation. Untuk dapat melakukan pengujian dan menyusun dokumentasi yang akurat, saya harus memahami berbagai bagian sistem yang tidak saya kerjakan secara langsung. Saya perlu memahami alur kerja backend, struktur database, endpoint API, deployment menggunakan Docker, konsep microservices, hingga mekanisme monitoring menggunakan Prometheus dan Grafana. Hal ini membutuhkan usaha tambahan karena saya harus mempelajari implementasi yang dibuat oleh anggota tim lain agar dapat memahami sistem secara menyeluruh.

Selain itu, dokumentasi harus selalu diperbarui mengikuti perkembangan proyek. Setiap perubahan pada endpoint API, struktur database, konfigurasi deployment, maupun arsitektur sistem harus segera dicatat dan diperbarui pada dokumentasi. Menjaga konsistensi antara implementasi aplikasi dan dokumentasi menjadi tantangan yang membutuhkan ketelitian dan perhatian terhadap detail.

## Pembelajaran yang Didapat

Melalui proyek SafeSpace, saya memperoleh banyak pembelajaran baik dari sisi teknis maupun non-teknis. Dari sisi teknis, saya mendapatkan pemahaman yang lebih baik mengenai pengembangan aplikasi cloud-native, penggunaan Docker untuk containerization, implementasi arsitektur microservices, monitoring menggunakan Prometheus dan Grafana, serta penggunaan GitHub Actions untuk mendukung proses Continuous Integration (CI).

Saya juga belajar bahwa dokumentasi memiliki peran yang sangat penting dalam pengembangan perangkat lunak. Dokumentasi yang baik tidak hanya membantu anggota tim memahami sistem, tetapi juga mempermudah proses deployment, maintenance, dan pengembangan fitur di masa mendatang. Pengalaman menyusun berbagai dokumen teknis membuat saya lebih memahami bagaimana menyajikan informasi teknis secara terstruktur dan mudah dipahami.

Dari sisi non-teknis, saya belajar mengenai pentingnya komunikasi, koordinasi, manajemen waktu, serta kerja sama tim. Saya menyadari bahwa kemampuan teknis yang baik perlu didukung oleh kemampuan berkolaborasi agar proyek dapat berjalan dengan efektif. Setiap anggota tim memiliki kontribusi yang berbeda dan keberhasilan proyek sangat dipengaruhi oleh kemampuan tim dalam berkomunikasi dan menyelesaikan masalah bersama.

## Refleksi Pribadi

Proyek SafeSpace memberikan pengalaman yang sangat berharga bagi saya karena memungkinkan saya untuk terlibat secara langsung dalam pengembangan aplikasi berbasis cloud. Sebelum mengikuti proyek ini, pemahaman saya mengenai konsep komputasi awan masih terbatas pada teori yang dipelajari di kelas. Namun melalui proyek ini, saya dapat melihat bagaimana konsep tersebut diterapkan dalam pengembangan aplikasi nyata.

Sebagai Lead QA & Documentation, saya belajar bahwa kualitas perangkat lunak tidak hanya ditentukan oleh keberhasilan implementasi fitur, tetapi juga oleh proses pengujian dan dokumentasi yang mendukung keberlangsungan sistem. Saya menjadi lebih memahami pentingnya melakukan validasi terhadap setiap fitur sebelum digunakan oleh pengguna serta pentingnya menyediakan dokumentasi yang lengkap dan mudah dipahami.

Pengalaman ini juga mengajarkan saya untuk melihat sistem secara lebih menyeluruh. Meskipun fokus utama saya berada pada pengujian dan dokumentasi, saya tetap perlu memahami cara kerja backend, database, deployment, dan integrasi antar service. Hal tersebut membantu saya mengembangkan pola pikir yang lebih luas dalam memahami suatu sistem perangkat lunak.

Ke depannya, saya ingin terus meningkatkan kemampuan di bidang quality assurance, software testing, serta technical documentation. 

## Kesimpulan

Secara keseluruhan, proyek SafeSpace memberikan pengalaman pembelajaran yang sangat bermanfaat dalam memahami implementasi konsep komputasi awan secara nyata. Peran sebagai Lead QA & Documentation membantu saya mengembangkan kemampuan teknis maupun profesional, khususnya dalam pengujian aplikasi, penyusunan dokumentasi, serta koordinasi dalam tim pengembang.

Melalui berbagai tantangan yang dihadapi selama proyek berlangsung, saya memperoleh pemahaman bahwa keberhasilan sebuah proyek tidak hanya bergantung pada teknologi yang digunakan, tetapi juga pada komunikasi, kerja sama tim, dan kemampuan untuk terus belajar. Pengalaman ini menjadi bekal yang sangat berharga untuk menghadapi proyek-proyek pengembangan perangkat lunak di masa depan.
