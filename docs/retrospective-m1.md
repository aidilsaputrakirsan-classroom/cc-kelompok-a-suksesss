# Retrospective — Milestone 1

## 🟢 Apa yang Berjalan Baik?
- Setup project (frontend, backend, database) berhasil dilakukan dengan baik
- Docker Compose berhasil dijalankan sehingga seluruh service dapat berjalan terintegrasi
- Struktur awal backend (FastAPI) dan frontend (React) sudah terbentuk dengan jelas
- Fitur utama (form konsultasi & dashboard BK) sudah dapat diimplementasikan
- Integrasi frontend dan backend berjalan dengan baik menggunakan REST API
- Pembagian role tim (Backend, Frontend, DevOps, QA & Docs) sudah cukup jelas

---

## 🔴 Apa yang Perlu Diperbaiki?
- Komunikasi tim masih kurang optimal (kadang terjadi miskomunikasi)
- Belum konsisten menggunakan Pull Request untuk setiap perubahan
- Dokumentasi belum lengkap di awal pengembangan
- Testing (QA) belum dilakukan secara sistematis sejak awal
- Beberapa bagian masih overlap (misalnya perubahan file tanpa koordinasi)

---

## 🔵 Action Items untuk Milestone 2
- Menggunakan GitHub Flow secara konsisten (branch → PR → review → merge)
- Setiap perubahan wajib melalui Pull Request (tidak push langsung ke main)
- Meningkatkan komunikasi tim (update progress secara rutin)
- Melakukan testing (blackbox & API testing) secara berkala
- Melengkapi dokumentasi (README, API docs, testing docs)
- Menambahkan code review untuk menjaga kualitas kode
- Memastikan setiap role fokus pada tanggung jawabnya masing-masing
